# Data Analysis and Visualization using Pandas

## Objective
To perform basic data analysis on a CSV file and visualize insights using
Matplotlib and Seaborn.

## Features
- Load CSV data using Pandas
- Calculate average values
- Bar chart, scatter plot, and heatmap visualizations

## Libraries Used
- Pandas
- Matplotlib
- Seaborn

## How to Run
1. Install dependencies:
   pip install pandas matplotlib seaborn
2. Run the script:
   python analysis.py

## Observations
- Higher advertising budgets generally result in higher sales
- Strong positive correlation between Advertising and Sales
